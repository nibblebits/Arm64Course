# Bitwise Masks Assignment

This assignment follows Lesson 34. Students implement three assembly
functions using the core bitwise instructions.

The directory contains:

- `starter/bitwise_assignment.s`: compilable stubs for students to replace;
- `solution/bitwise_assignment.s`: the published reference solution; and
- `test.c`: shared tests for both implementations.

Build both versions:

```sh
make
```

Run the starter tests (expected to fail before the assignment is completed):

```sh
make run-starter
```

Run the published solution:

```sh
make run-solution
```
